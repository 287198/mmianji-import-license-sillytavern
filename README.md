# 眠眠机验证（SillyTavern 扩展）

这个扩展提供两项互相独立的功能：

- **导入许可验证**：提交眠眠机设置页生成的六位验证码。
- **社区入群审核**：直接在酒馆扩展内完成社区承诺和五道题，全部通过后取得审核群号。

扩展不会读取、统计、搜索或上传聊天记录、角色、预设、世界书、图片、API 密钥、酒馆账号或设备信息，也不申请服务器插件权限。

## 安装与使用

1. 在 SillyTavern 的“扩展 → 安装扩展”中粘贴 `https://github.com/287198/mmianji-import-license-sillytavern`。
2. 打开扩展设置里的“眠眠机验证”。
3. 导入许可：在眠眠机“设置 → 导入许可验证”取得六位验证码，并在五分钟内提交。
4. 社区审核：点击“开始审核”，完整输入承诺并依次回答五道题。

导入许可结果绑定眠眠机账号，可跨设备使用，验证码一次有效。社区审核不绑定眠眠机账号；服务端仅按不可逆 IP 哈希执行次数限制。

## 隐私边界

扩展源码只包含 DOM 界面和 HTTPS 请求。服务端只会收到：

- 导入许可六位验证码；或
- 社区审核中用户主动填写的承诺、答案和短期签名令牌；
- 网关侧用于限流的网络地址，该地址只以不可逆 HMAC 哈希保存。

服务端不会收到任何酒馆内容。正确答案、签名密钥和审核群号也不会写入公开扩展源码；群号只在完整审核通过后由服务端返回。
