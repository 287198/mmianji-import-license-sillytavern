# 眠眠机导入许可（SillyTavern 扩展）

这个最小扩展只完成一件事：把眠眠机设置页生成的六位验证码提交给导入许可服务。

它不会读取或上传聊天记录、角色、预设、世界书、图片或 API 密钥，也不申请服务器插件权限。

## 安装与使用

1. 在 SillyTavern 的“扩展 → 安装扩展”中粘贴 `https://github.com/287198/mmianji-import-license-sillytavern`。
2. 在眠眠机“设置 → 导入许可验证”点击“开始导入许可验证”，得到六位验证码。
3. 打开 SillyTavern 扩展面板里的“眠眠机导入许可”，五分钟内提交验证码。

验证结果只绑定眠眠机账号，可跨设备使用。验证码一次有效。

## 隐私边界

扩展源码只有 DOM 界面和一次 HTTPS 请求。服务收到验证码以及服务侧用于防滥用的网络标识；不会收到酒馆内容。
